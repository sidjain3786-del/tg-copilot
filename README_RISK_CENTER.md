# Risk Center Update

Added a separate Risk Center tab to Trader Co-Pilot.

Features:
- Position sizing calculator
- Account balance + risk %
- Entry / Stop Loss / Target calculation
- Point/unit value support
- Max risk, risk per unit, position size, potential profit, R:R
- Daily and weekly loss budget cards
- Consecutive loss streak monitor
- Configurable money-management rules
- Pre-trade risk gate
- R-multiple reference cards
- Responsive desktop/mobile layout

Risk settings are persisted in browser localStorage for the signed-in browser/device. Trade history remains stored in D1 as before.
